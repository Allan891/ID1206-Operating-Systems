##Question 6: Thread creation, termination, and synchronization
This program creates an array of N random numbers whose values are in the range of [0,1]. It will then print the sum and the time (in seconds) that it took to perform the calculation, first by sequentially adding the values, then by parallelizing. The number of threads are defined by the user during runtime.

To compile:

```make```

To run:

```./pthread_sum T```

where T is the number of threads
